# Dataset

Sumber: Kaggle - **Ice Cream Revenue** (file `IceCreamData.csv`, kolom `Temperature` dan `Revenue`, 500 baris).

Cara unduh:
1. Buka halaman dataset di Kaggle (cari "Ice Cream Revenue"), klik **Download**.
2. Ekstrak, taruh file di folder ini dengan nama `IceCreamData.csv`.
3. Atau lewat CLI: `kaggle datasets download -d vinicius150987/ice-cream-revenue -p data --unzip`

Lalu jalankan `python train.py`.
